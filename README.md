# Словоград

«Словоград» — интерактивный тренажёр по составу слова для ученика 2 класса. Ребёнок узнаёт, зачем нужны приставка, корень, суффикс и окончание, и учится обозначать их так же, как в школьной тетради.

На сайте есть конструктор слов, пошаговая мастерская разбора, примеры однокоренных слов с переключателем школьных значков, игры с подсказками, викторина и памятка для печати. Страница рассчитана на компьютер, планшет и телефон.

## Как открыть локально

Скачайте `index.html` и откройте его двойным щелчком в браузере. Стили, иллюстрации и скрипты уже внутри файла: интернет, установка пакетов и сборка не нужны. Для упражнений в браузере должен быть включён JavaScript.

Если хотите открыть сайт через локальный HTTP-сервер, выполните в папке проекта (требуется Python 3):

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Сервер можно остановить клавишами `Ctrl+C`.

## Как опубликовать через GitHub Pages

1. В репозитории `ArtIgnat2000/slovograd` откройте **Settings → Pages**. В разделе **Build and deployment → Source** должен быть выбран **GitHub Actions**.
2. После попадания `.github/workflows/pages.yml` в `main` сайт будет публиковаться автоматически при обновлении этой ветки. Workflow загружает только `index.html`; сборка и дополнительные секреты не нужны.
3. Для ручной публикации откройте **Actions → Deploy to GitHub Pages → Run workflow** и выберите `main`.
4. После успешного запуска сайт открывается по адресу [https://artignat2000.github.io/slovograd/](https://artignat2000.github.io/slovograd/). Если запуск завершился ошибкой, откройте его в **Actions**, чтобы посмотреть, на каком шаге она возникла.

## Файлы проекта

- `index.html` — весь сайт: разметка, оформление, иллюстрации и логика упражнений.
- `.github/workflows/pages.yml` — автоматическая публикация через GitHub Actions.
- `.nojekyll` — отключает Jekyll при публикации из ветки; текущий workflow этот файл не использует.
- `README.md` — эта инструкция.

## Быстрая проверка после изменений

Отдельного набора автотестов в репозитории нет. Для проверки в браузере:

1. Проверьте, что в схеме порядка частей и во всех четырёх карточках разбирается слово «посадка»: `по-`, `-сад-`, `-к-`, `-а`. В карточке окончания переключитесь на `-ой`: слово и предложение должны показать «посадкой», а основа «посадк» — сохраниться.
2. Конструктор должен начинаться с «посадки». Сравните «Сад» и «Садик»: у обоих нулевое окончание, а в слове «садик» есть суффикс `-ик-`. Проверьте подсказку для незнакомого сочетания и возврат к «посадке».
3. В разделе однокоренных слов сначала должна открываться семья «Сад». Смените семью и выключите и включите школьные значки. Пройдите мастерскую, игру про однокоренные слова и викторину: первые четыре вопроса викторины должны быть про «посадку». Проверьте объяснения, итоговый счёт и повторный запуск.
4. Повторите несколько действий на узком экране. Нажмите «Распечатать памятку»: в предварительном просмотре должны остаться памятка и школьные обозначения, без игр и меню.
