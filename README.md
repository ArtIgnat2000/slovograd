# Словоград

«Словоград» — интерактивный тренажёр по составу слова для ученика 2 класса. Ребёнок узнаёт, зачем нужны приставка, корень, суффикс и окончание, и учится обозначать их так же, как в школьной тетради.

На сайте есть конструктор слов, пошаговая мастерская разбора, примеры однокоренных слов с переключателем школьных значков, игры с подсказками, викторина и памятка для печати. Страница рассчитана на компьютер, планшет и телефон.

## Как открыть локально

Скачайте `index.html` и откройте его двойным щелчком в браузере. Стили, иллюстрации и скрипты уже внутри файла: интернет, установка пакетов и сборка не нужны. Для упражнений в браузере должен быть включён JavaScript.

Если хотите открыть сайт через локальный HTTP-сервер, выполните в папке проекта (требуется Python 3):

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Сервер можно остановить клавишами `Ctrl+C`.

## Как опубликовать через GitHub Pages

1. В репозитории `ArtIgnat2000/slovograd` откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
3. В поле **Branch** выберите ветку, в корне которой находится `index.html`: это может быть рабочая ветка или `main`, если сайт уже добавлен в неё. Для папки выберите **`/(root)`**, затем нажмите **Save**.
4. После завершения публикации откройте ссылку из **Settings → Pages**. Стандартный адрес проекта: [https://artignat2000.github.io/slovograd/](https://artignat2000.github.io/slovograd/).

## Файлы проекта

- `index.html` — весь сайт: разметка, оформление, иллюстрации и логика упражнений.
- `.nojekyll` — пустой файл, чтобы GitHub Pages отдавал сайт без обработки Jekyll.
- `README.md` — эта инструкция.

## Быстрая проверка после изменений

Отдельного набора автотестов в репозитории нет. Для проверки в браузере:

1. Откройте главную страницу и перейдите к разделам по ссылкам в меню. В карточках нажмите «Ещё примеры», попробуйте поменять приставку у слова «ход» и окончание у слова «книга».
2. В конструкторе выберите «Домик», чтобы увидеть нулевое окончание и школьный разбор. Проверьте, что для незнакомого сочетания появляется подсказка, а кнопка «Начать с „посадки“» возвращает исходное слово.
3. Пройдите мастерскую, игру про однокоренные слова и викторину. Проверьте объяснения при верном и неверном ответе, итоговый счёт и повторный запуск. В разделе однокоренных слов также смените семью и выключите и включите школьные значки.
4. Повторите несколько действий на узком экране. Нажмите «Распечатать памятку»: в предварительном просмотре должны остаться памятка и школьные обозначения, без игр и меню.
